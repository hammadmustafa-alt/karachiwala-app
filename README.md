Karachiwala

Installable Android releases of Karachiwala, an independent civic reporting app for Karachi. This is not a government app.

Download: go to https://www.karachiwala.pk/download for the latest release and install steps.

This repository only hosts app releases. It does not contain source code and the app is not open source.
